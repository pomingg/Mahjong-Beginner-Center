# 麻將新手訓練中心 Mahjong Beginner Center

台灣麻將（16 張）的出牌訓練工具，線上直接玩：**https://pomingg.github.io/Mahjong-Beginner-Center/**

麻將是一個高度依賴經驗與判斷力的遊戲，每一手牌、每一次摸牌的狀況都不一樣，新手很難單靠實戰慢慢累積出「該打哪張、該怎麼湊牌」的心法。這個工具讓你反覆面對隨機產生的手牌，在打牌前先看懂目前的牌型、練習判斷去留，打牌後再得到量化、可解釋的回饋——目標是培養效率判斷的直覺，回到真實牌桌時能更快做出合理決策。

## 這個工具在教什麼

每一巡（摸牌後、打牌前）都會先分析目前的手牌，用「聽牌」當唯一具體的目標，講你能聽懂的話：

- **牌型判斷**：手上已經湊好哪些面子、哪些搭子快湊成一組、哪一對可以留著當最後那一對
- **取捨邏輯**：留哪張、丟哪張才能讓你更接近聽牌，以及為什麼
- **孤張辨識**：哪些牌丟了完全不影響進度，是可以優先考慮丟掉的孤張

打牌之後會立刻看到回饋（你的選擇 vs. 最佳解），一整局（最多 17 巡）結束後會有命中率統計與鼓勵語。

刻意不使用「向聽數」「進張」這類源自日本立直麻將分析理論、台灣牌桌上不會這樣講的詞彙，全程用口語講因果邏輯。

## 技術棧

React 18 + TypeScript + Vite，CSS Modules，Vitest 測試，GitHub Actions 自動跑測試並部署到 GitHub Pages。

核心的向聽數／進張演算法是獨立的引擎模組（`src/engine/`），與 UI 完全分離；用暴力法 oracle 對數百組隨機手牌做交叉驗證確保正確性。

## 本地開發

```bash
npm install
npm run dev        # 啟動開發伺服器
npm run test       # 跑測試
npm run typecheck  # TypeScript 型別檢查
npm run lint       # ESLint
npm run build      # 產出正式版靜態檔案
```
